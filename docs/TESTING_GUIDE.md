# 测试指南 —— 记忆/反思/人格/情绪类功能怎么验证

> 心智功能的特殊之处：代码不报错 ≠ 功能工作。
> 三层测试法：**代码层（单测）→ 数据层（查表）→ 行为层（对话实验）**，
> 另加一层"长期层"（周级评估）。

## 一、总纲

| 层 | 测什么 | 工具 | 时机 |
|---|---|---|---|
| 代码层 | 检测器/切块器/评分函数等纯逻辑 | pytest | 每次改动 |
| 数据层 | "写进哪张表、字段对不对" | sqlite3 直查 | 功能上线后 |
| 行为层 | 对话表现是否符合预期 | 固定问题集 | 每次大改后 |
| 长期层 | 跨天/跨重启的稳定性 | 周报/日常使用 | 持续 |

核心原则：**固定输入 → 预期输出 → 可复现**。
数据层验证"存对了没"，行为层验证"想得起没"——两层都过才是真功能。

## 二、分功能测试清单（对照本项目）

### 记忆
| 层 | 测试用例 | 预期 |
|---|---|---|
| 代码 | pytest：去重/检索兜底/评分 | 45 测试全绿 |
| 数据 | 聊"我在做X"→ 查 memories 有原文；4h 后查 facts 有三元组 | 两表都有记录 |
| 行为 | 聊 A → 聊别的 → 再提 A | 回复引用 A 的细节 |
| 行为 | **跨重启问同一事实**（"你叫什么名字"） | 仍记得——"小月失忆"就是这层发现的 |
| 行为 | 问知识库外的东西 | 诚实说没有（防幻觉） |

### 反思（自省/周报/小结）
| 层 | 测试用例 | 预期 |
|---|---|---|
| 代码 | pytest：纠正信号检测（"不对…"触发、"今天天气"不触发） | 已有 test_self_reflect |
| 数据 | 说"不对，应该是X"→ 查 lessons 表 | 新增一行含原话+上下文 |
| 行为 | 纠正后再问同话题 | 按纠正后的说法回答 |
| 数据 | 手动触发周报 → 核对报告数字 | 对话数/git 数与 stats 一致（无幻觉） |
| 数据 | 无活动日触发每日小结 | 返回 skipped（不烧 LLM 不瞎编） |

### 人格（画像/风格）
| 层 | 测试用例 | 预期 |
|---|---|---|
| 数据 | 连续聊技术话题后查 profile 表 | technical_background 等维度更新，confidence 合理 |
| 行为 | 同一问题间隔一天再问 | 回答风格/立场一致（一致性测试） |
| 行为 | 说"很好，就这样"→ 再问新问题 | 回答形式向范例靠拢（主观可感知） |

### 情绪（未来实现时）
| 层 | 测试用例 | 预期 |
|---|---|---|
| 代码 | PAD/valence-arousal 状态机单测 | 情绪输入→轨迹变化符合模型 |
| 行为 | 输入"烦死了，今天 bug 调一天" | 回复有共情（不是冷冰冰给方案） |
| 行为 | 情绪状态影响回复语气 | 不同情绪下同一问题的措辞不同 |

## 三、"对话回归集"——行为层的核心工具

像检索评测的 TEST_SET 一样，给聊天建一份**固定问题集**（10 题左右），
每次大改后原样问一遍，对比回答质量：

```python
# benchmarks/chat_regression.py 的雏形（建议实现）
CHAT_REGRESSION = [
    ("你叫什么名字？", "应回答设定的名字，不遗忘"),
    ("我最近在做哪个项目？", "应引用 facts 里的项目信息"),
    ("我记得上次说过 RAG 调优，进展如何？", "应召回历史对话细节"),
    ("知识库里有 Python 装饰器的资料吗？", "应诚实说没有"),
    ("记录：下午2-4点调参", "应回复已记录并解析时间"),
    ("不对，重排序应该放在检索之后", "应接受纠正并记住"),
    ...
]
```

每次发版前跑一遍，人工记录每题的"通过/退化"，防止改 A 坏 B。

## 四、拟人化功能怎么测（9-01 新增）

这几项的共同难点：**没有"正确答案"，只有"像不像人"**。所以每项都配一条
反向验证——正向通过容易碰巧，反向不该触发才是真判据。

### 教训去重与身份优先
| 层 | 测试用例 | 预期 |
|---|---|---|
| 代码 | `pytest tests/test_self_reflect.py` | 8 测试全绿（含迁移幂等） |
| 数据 | 同一句纠正连发 3 次 → 查 `lessons` | **只有一行**，`created_at` 刷新 |
| 数据 | 查 `kind` 分类 | "你就叫小月吧"= `identity` |
| 行为 | 连发 6 条"不对，XXX"后问"你叫什么名字" | 仍答小月（identity 不占配额） |
| 反向 | 反复改名 | identity 段有 5 条上限，不无界膨胀 |

### 自我状态
| 层 | 测试用例 | 预期 |
|---|---|---|
| 代码 | `pytest tests/test_self_state.py` | 9 测试（含访客隔离） |
| 数据 | `get_self_state_injection()` 当天首句 vs 聊 10 轮后 | 档位从"刚开口"→"聊开了" |
| 行为 | 连聊 10 轮 | 不再用见面式寒暄（主观可感） |
| 反向 | 以访客 user_id 调用 | 不含"刚被纠正"（`lessons` 是主人表） |

### 隔日情绪跟进（必须跨天）
| 层 | 测试用例 | 预期 |
|---|---|---|
| 代码 | `pytest tests/test_mood.py -k yesterday` | 6 测试 |
| 行为 | 今天说 2 句烦躁 → **明天**第一句话 | 轻轻问一句"昨天那事顺了吗" |
| 反向 | 明天**第二句**之后 | **不再提昨天**（问两遍就成唠叨） |
| 反向 | 昨天只 1 条负面 / 全是开心 | 不触发（阈值 2 且只看负面） |

### 主动开口（默认关闭）
| 层 | 测试用例 | 预期 |
|---|---|---|
| 代码 | `pytest tests/test_initiative.py` | 18 测试（四条硬约束全覆盖） |
| 数据 | 未开启时手动调 `run_initiative()` | `skipped: 主动开口未启用` |
| 行为 | 开启后观察 22:10 那条消息 | 引用**当天具体事实**，不是"今天辛苦了" |
| 反向 | 连续 3 天不回 | 自动降频到每周 1 条 |
| 反向 | 23:00-08:00 期间 | 静默，一条不发 |

## 五、对话回归集（已实现）

`benchmarks/chat_regression.py` —— 第三节的"建议实现"已落地。

```bash
cd server
.venv/bin/python benchmarks/chat_regression.py            # 真实库（能测记忆召回，会留对话痕迹）
.venv/bin/python benchmarks/chat_regression.py --dry-run  # 临时库，零污染（依赖真实数据的题自动跳过）
.venv/bin/python benchmarks/chat_regression.py -k 名字     # 只跑某题
```

10 题覆盖身份锚定、真实记忆召回、防幻觉、命令解析、接受纠正、承认不确定、
无 Markdown 格式。报告含通过/退化表格 + 真实 token 用量 + 成本折算。

**判据的局限要知道**：用的是关键词命中，不是语义评分。能抓住"失忆/答错/
幻觉"这类硬退化，抓不住"语气变差"这类软退化——所以报告默认打印回复原文，
软退化仍需人眼看。首版判据自己就写错了两题（她说"我不太**确定**"，判据写死
"不确定"匹配不到；时间答"2:22"而判据期望"点"），**判据本身也要先被验证**。

成本参考（`deepseek-v4-flash` via opencode zen，实测非估算）：
单轮输入约 6,000 tok、输出约 300 tok，10 题一次 **0.09 元**（高峰）/
**0.045 元**（非高峰，北京时间 9-12 与 14-18 点之外）。前缀缓存实测命中
31%-76%，缓存单价比输入便宜 30 倍——稳定档案区放在 prompt 前部就是为这个。
