# 测试指南 —— 记忆/反思/人格/情绪类功能怎么验证

> 心智功能的特殊之处：代码不报错 ≠ 功能工作。
> 三层测试法：**代码层（单测）→ 数据层（查表）→ 行为层（对话实验）**，
> 另加一层"长期层"（周级评估）。

## 一、总纲

| 层 | 测什么 | 工具 | 时机 |
|---|---|---|---|
| 代码层 | 检测器/切块器/评分函数等纯逻辑 | pytest | 每次改动 |
| 数据层 | "写进哪张表、字段对不对" | sqlite3 直查 | 功能上线后 |
| 行为层 | 对话表现是否符合预期 | 固定问题集 | 每次大改后 |
| 长期层 | 跨天/跨重启的稳定性 | 周报/日常使用 | 持续 |

核心原则：**固定输入 → 预期输出 → 可复现**。
数据层验证"存对了没"，行为层验证"想得起没"——两层都过才是真功能。

## 二、分功能测试清单（对照本项目）

### 记忆
| 层 | 测试用例 | 预期 |
|---|---|---|
| 代码 | pytest：去重/检索兜底/评分 | 45 测试全绿 |
| 数据 | 聊"我在做X"→ 查 memories 有原文；4h 后查 facts 有三元组 | 两表都有记录 |
| 行为 | 聊 A → 聊别的 → 再提 A | 回复引用 A 的细节 |
| 行为 | **跨重启问同一事实**（"你叫什么名字"） | 仍记得——"小月失忆"就是这层发现的 |
| 行为 | 问知识库外的东西 | 诚实说没有（防幻觉） |

### 反思（自省/周报/小结）
| 层 | 测试用例 | 预期 |
|---|---|---|
| 代码 | pytest：纠正信号检测（"不对…"触发、"今天天气"不触发） | 已有 test_self_reflect |
| 数据 | 说"不对，应该是X"→ 查 lessons 表 | 新增一行含原话+上下文 |
| 行为 | 纠正后再问同话题 | 按纠正后的说法回答 |
| 数据 | 手动触发周报 → 核对报告数字 | 对话数/git 数与 stats 一致（无幻觉） |
| 数据 | 无活动日触发每日小结 | 返回 skipped（不烧 LLM 不瞎编） |

### 人格（画像/风格）
| 层 | 测试用例 | 预期 |
|---|---|---|
| 数据 | 连续聊技术话题后查 profile 表 | technical_background 等维度更新，confidence 合理 |
| 行为 | 同一问题间隔一天再问 | 回答风格/立场一致（一致性测试） |
| 行为 | 说"很好，就这样"→ 再问新问题 | 回答形式向范例靠拢（主观可感知） |
| 行为 | **风格漂移**：故意诱导它换风格 | 不应轻易改变（lessons/facts 锚定） |

### 情绪（未来实现时）
| 层 | 测试用例 | 预期 |
|---|---|---|
| 代码 | PAD/valence-arousal 状态机单测 | 情绪输入→轨迹变化符合模型 |
| 行为 | 输入"烦死了，今天 bug 调一天" | 回复有共情（不是冷冰冰给方案） |
| 行为 | 情绪状态影响回复语气 | 不同情绪下同一问题的措辞不同 |
| 评测 | 行业基准：EMPATHETICDIALOGUES 等数据集 | 定量指标 |

## 三、"对话回归集"——行为层的核心工具

像检索评测的 TEST_SET 一样，给聊天建一份**固定问题集**（10 题左右），
每次大改后原样问一遍，对比回答质量：

```python
# benchmarks/chat_regression.py 的雏形（建议实现）
CHAT_REGRESSION = [
    ("你叫什么名字？", "应回答设定的名字，不遗忘"),
    ("我最近在做哪个项目？", "应引用 facts 里的项目信息"),
    ("我记得上次说过 RAG 调优，进展如何？", "应召回历史对话细节"),
    ("知识库里有 Python 装饰器的资料吗？", "应诚实说没有"),
    ("记录：下午2-4点调参", "应回复已记录并解析时间"),
    ("不对，重排序应该放在检索之后", "应接受纠正并记住"),
    ...
]
```

每次发版前跑一遍，人工记录每题的"通过/退化"，防止改 A 坏 B。
